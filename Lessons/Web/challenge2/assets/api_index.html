IDroid Server Edge API Index

Welcome! The following endpoints are currently exposed by the terminal network router:

GET/api

Serves the automated machine-readable JSON route index discovery frame.

GET/api/status

Returns application uptime metrics and running configurations as a JSON frame.

GET/api/cores

Exposes active runtime processing unit calculations and CPU core availability limits.

POST/api/config

Mutates terminal title options. Requires URL-Encoded payload body: server_label=YourValue
